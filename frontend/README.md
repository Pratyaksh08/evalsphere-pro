# EvalSphere Frontend

Next-Gen Student Assessment and Evaluation Web Application.

## Structure
- `index.html` — Application root structure, SEO metadata, top navigation bar.
- `style.css` — Modern design system with dark mode glassmorphism, responsive grid, and typography.
- `script.js` — Interactive Dashboard, All Subjects curriculum explorer, MCQ test runner, C compiler arena, SQL studio, and scorecard analytics.

## Running
When the backend is started (`npm start` in `backend/` or root workspace), the frontend is automatically served at `http://localhost:3000`.
You can also open `index.html` directly with VS Code Live Server.
